## 시험 직전 30초 — 이것만은

### 분류 지표 (혼동행렬)

|  | 예측 X | 예측 O |
| --- | --- | --- |
| **실제 X** | TN | **FP** 헛짚음 |
| **실제 O** | **FN** 놓침 | TP |

| 지표 | 식 | 외우는 법 |
| --- | --- | --- |
| Accuracy | (TP+TN) / 전체 | 전부 |
| **Precision** | TP / (TP+**FP**) | 분모에 **FP** → 헛짚음 관리 |
| **Recall** | TP / (TP+**FN**) | 분모에 **FN** → 놓침 관리 |
| F1 | 2PR / (P+R) | 조화평균 |

> 놓치면 큰일(암·사기) → **Recall** · 헛짚으면 큰일(스팸) → **Precision**
> **불균형 데이터면 Accuracy 대신 AUC** (전부 다수클래스로 찍었을 때 몇 %인지 먼저 계산)

### 회귀 지표

| 지표 | 식 | 성질 |
| --- | --- | --- |
| MAE | 오차 **절댓값** 평균 | 이상치에 둔감 |
| MSE | 오차 **제곱** 평균 | 이상치에 매우 민감 |
| RMSE | **√MSE** | 민감 + 단위 복원 |
| R² | 1 − SSE/SST | **1=완벽, 0=평균으로 찍기, 음수 가능** |

> RMSE ≥ MAE 는 **항상** 성립 (검산에 활용)

### 기타 핵심

| 개념 | 한 줄 |
| --- | --- |
| 지도/비지도/강화 | 정답 있음 / 아무 피드백 없음 / **보상만** 있음 |
| Ridge vs Lasso | 0에 **가깝게** vs 정확히 **0으로** (자동 변수선택) |
| Decision Tree vs RF | 1개(불안정) vs 여러 개 **투표**(오차 상쇄) |
| SVM | **margin 최대** 경계, 커널로 차원 상승 |
| K-Means / DBSCAN | k 지정·구형에 강함 / k 불필요·**밀도 차이 없으면 실패** |
| PCA | 중복 제거·차원 축소, 단 **주성분은 해석이 어렵다** |
| 과적합 | Train 좋음 + Val 나쁨 (Gap 큼) |
| 과소적합 | **Train부터 나쁨** (Gap 작아도 나쁜 것) |

## 5. 비지도학습 — 군집화 · PCA

**[UNS-1]** (객관식 · 기본)

다음은 K-Means, Hierarchical(계층적 군집), DBSCAN 을 비교한 설명이다. 옳지 않은 것은?
① K-Means 는 군집 개수 k 를 분석자가 미리 정해야 하며, 동그란(구형) 덩어리 모양의 군집에 강하다
② Hierarchical 은 가까운 것부터 하나씩 합쳐 올라가며 덴드로그램을 만들므로, k 를 나중에 정할 수 있다
③ DBSCAN 은 k 를 정할 필요가 없고, 모든 데이터 점을 반드시 어느 한 군집에 배정한다
④ DBSCAN 은 빽빽한(밀도가 높은) 곳만 군집으로 인정하므로, 밀도 차이가 없는 데이터에서는 군집화에 실패한다

**[UNS-2]** (계산 · 응용)

군집 결과에서 두 데이터 점의 거리를 재었더니 다음과 같았다.
· 점 A : 같은 군집 안의 다른 점들과의 평균 거리 a = 2, 가장 가까운 다른 군집의 점들과의 평균 거리 b = 5
· 점 B : a = 5, b = 2

## 1. 기계학습 개요 · 지도/비지도 구분

**[BAS-1] 정답 — ②**

세 가지 학습 유형을 가르는 기준은 '정답(라벨)이 있느냐'입니다. ①과 ③은 맞혀야 할 정답(매출액, 스팸 여부)이 데이터에 붙어 있으므로 지도학습이고, ④는 정답 대신 '점수(보상)'를 받으며 시행착오로 배우는 강화학습입니다. ②만 정답 없이 데이터가 비슷한 것끼리 스스로 뭉치게 하는 군집화이므로 비지도학습입니다.

> ⚠️ **함정** — ②의 '4개 그룹으로 나눈다'를 보고 분류(지도학습)로 착각하기 쉽습니다. 그룹의 정답 이름표가 미리 주어졌으면 분류지만, 여기서는 이름표 없이 기계가 알아서 묶는 것이라 군집화입니다. 또 ④를 '정답이 없으니 비지도'라고 고르는 실수도 잦습니다.

**[BAS-2] 정답 — X**

강화학습에는 정답 라벨은 없지만 대신 '보상(reward)'이라는 피드백이 있습니다. 비지도학습은 라벨도 보상도 없이 데이터의 구조(비슷한 것끼리 묶기, 차원 축소)만 찾는 반면, 강화학습은 보상을 최대로 만드는 '행동'을 시행착오로 배웁니다. 그래서 교재도 지도·비지도·강화를 나란한 세 범주로 구분합니다.

> ⚠️ **함정** — '라벨이 없다 = 비지도학습'이라는 단순 암기가 함정입니다. 구분 기준을 '라벨이 있다 / 아무 피드백도 없다 / 보상만 있다' 세 갈래로 기억해야 합니다.

**[BAS-3] 정답 — ③**

회귀는 '연속된 숫자 값'을, 분류는 '어느 범주에 속하는가'를 맞히는 문제입니다. ③의 0~9는 숫자처럼 보이지만 실제로는 '0번 칸, 1번 칸 …' 같은 10개의 이름표(범주)일 뿐이어서, 3과 7 사이에 크고 작음이나 평균 같은 의미가 없습니다. 따라서 ③은 다중 분류이고 나머지는 회귀입니다.

> ⚠️ **함정** — 라벨이 숫자로 적혀 있으면 무조건 회귀라고 판단하는 것이 함정입니다. '그 숫자끼리 더하거나 평균을 내는 게 말이 되는가'를 따져 보면 구분됩니다. 참고로 ③에 RMSE를 쓰면 '3을 5로 예측'과 '3을 9로 예측'의 벌점이 달라져 버려 말이 안 됩니다.

**[BAS-4] 정답 — (1) TP=60, FP=140, FN=40, TN=760 (2) Accuracy 0.82, Precision 0.30, Recall 0.60, F1 0.40 (3) 전부 미가입 모델은 0.90 으로 오히려 더 높다**

'가입'이라 예측한 200명 중 60명이 맞았으니 TP=60, 나머지 140명은 헛짚음이라 FP=140입니다. 실제 가입자 100명 중 60명만 잡았으니 놓친 FN=40이고, 남은 TN=1000−60−140−40=760입니다. Accuracy=(60+760)/1000=0.82, Precision=60/200=0.30, Recall=60/100=0.60, F1=2×(0.30×0.60)/(0.30+0.60)=0.36/0.9=0.40이며, 전부 미가입으로 찍으면 900명을 맞혀 0.90이 나옵니다.

> ⚠️ **함정** — Accuracy 0.82가 기준선 0.90보다 낮다고 해서 '아무것도 안 하는 모델보다 못하다'고 결론 내면 안 됩니다. 전부 미가입 모델은 가입자를 단 한 명도 찾지 못하지만(Recall=0, AUC=0.5) 이 모델은 60명을 찾아냅니다. 실습4에서 Accuracy 0.8830 vs 0.8938은 붙어 있는데 AUC가 0.5000 vs 0.7913으로 갈렸던 것과 같은 상황으로, 불균형 데이터에서는 Accuracy가 아니라 Recall·F1·AUC를 봐야 합니다.

**[BAS-5] 정답 — (1) MAE = 2.5 (2) MSE = 9, RMSE = 3 (3) RMSE**

각 오차(실제−예측)는 0, +2, +4, −4이므로 절댓값은 0, 2, 4, 4이고 MAE=(0+2+4+4)/4=10/4=2.5입니다. 제곱하면 0, 4, 16, 16이므로 MSE=36/4=9이고 RMSE=√9=3입니다. RMSE는 오차를 제곱해서 더하므로 큰 오차 하나가 훨씬 크게 반영되어, 이상치가 생기면 MAE보다 RMSE가 급격히 나빠집니다(교재 예: 이상치 1개 추가 시 MAE 2배, RMSE 4배, MSE 16배).

> ⚠️ **함정** — 오차의 부호를 그대로 더해 (0+2+4−4)/4=0.5 로 계산하는 실수가 가장 흔합니다. MAE는 반드시 절댓값을 씌운 뒤 평균을 내야 하며, 또 RMSE(3)가 MAE(2.5)보다 항상 크거나 같다는 점도 검산에 쓸 수 있습니다.

**[BAS-6] 정답 — (가) 회귀 — MAE(또는 RMSE, R²) / (나) 분류 — Accuracy(또는 Precision, Recall, F1, ROC-AUC)**

예측 대상이 '얼마인가'라는 연속된 숫자면 회귀, '어느 쪽인가'라는 범주면 분류입니다. (나)는 원래 숫자였던 매매가를 5억이라는 기준으로 잘라 '넘는다/못 넘는다' 두 범주로 바꾼 것이므로 분류가 됩니다. 문제 유형이 정해지면 쓸 수 있는 지표도 함께 정해져서, (가)에 Accuracy를 쓰거나 (나)에 RMSE를 쓸 수는 없습니다.

> ⚠️ **함정** — (나)도 원래 데이터가 금액(숫자)이라는 이유로 회귀라고 답하기 쉽습니다. 기준은 '입력 데이터가 숫자인가'가 아니라 '모델이 최종적으로 내놓는 답이 숫자인가 범주인가'입니다. 또 (가)와 (나)의 성능을 하나의 지표로 나란히 비교하려는 것도 잘못된 접근입니다.


## 2. 회귀 알고리즘과 회귀 지표

**[REG-1] 정답 — ③**

Linear Regression은 규제가 아예 없고, Ridge(L2)는 계수를 0에 '가깝게' 줄이기만 할 뿐 정확히 0으로 만들지는 않습니다. Lasso(L1)만 계수를 딱 0으로 눌러버려서 그 변수를 아예 안 쓰게 되고, 이것이 자동 변수 선택 효과입니다. 규제는 실습1 XGBoost의 reg_lambda처럼 모델이 과하게 커지지 않도록 잡아주는 '제동 손잡이'와 같은 개념입니다.

> ⚠️ **함정** — Ridge도 계수를 '줄인다'는 점 때문에 ②를 고르기 쉽습니다. 줄이는 것(Ridge)과 0으로 만드는 것(Lasso)은 다릅니다.

**[REG-2] 정답 — MAE = 4.5, MSE = 25, RMSE = 5, R² = 0.8**

먼저 오차(ŷ − y)는 +1, +5, +5, −7 입니다. 절댓값을 더하면 1+5+5+7 = 18, 이를 4로 나눠 MAE = 4.5. 제곱해서 더하면 1+25+25+49 = 100(=SSE), 4로 나눠 MSE = 25이고 여기에 루트를 씌워 RMSE = 5입니다. R²는 1 − SSE/SST인데 SST = 15²+5²+5²+15² = 500이므로 R² = 1 − 100/500 = 0.8입니다.

> ⚠️ **함정** — RMSE를 MAE에 루트를 씌운 값으로 착각하기 쉽습니다. RMSE는 반드시 MSE에 루트를 씌운 값입니다. 또 MSE를 구할 때 −7을 부호 그대로 더하면 안 되고, 제곱하면 부호가 사라진다는 점을 기억해야 합니다.

**[REG-3] 정답 — X**

R² = 1 − SSE/SST 이므로, 모델의 오차 제곱합(SSE)이 평균으로만 예측했을 때의 오차 제곱합(SST)보다 커지면 R²는 음수가 됩니다. 즉 '평균으로 찍는 것보다도 못한 모델'일 때 음수가 나오며, 이는 계산 오류가 아니라 실제로 자주 관측되는 정상적인 결과입니다.

> ⚠️ **함정** — '0~1 사이'라는 설명만 외우면 음수를 오류로 판단합니다. 상한은 1이지만 하한은 없습니다.

**[REG-4] 정답 — 전: MAE 2, RMSE 2 / 후: MAE 3.2, RMSE 4 → MAE 1.6배, RMSE 2배**

전에는 오차가 전부 2라서 MAE = 2, MSE = 4, RMSE = 2 입니다. 후에는 오차가 2,2,2,2,8 이 되어 MAE = (2+2+2+2+8)/5 = 16/5 = 3.2, MSE = (4+4+4+4+64)/5 = 80/5 = 16, RMSE = √16 = 4 입니다. 똑같이 이상치 1개가 들어왔는데 MAE는 1.6배 커진 반면 RMSE는 2배(MSE는 4배) 커졌습니다. 오차를 제곱하는 지표일수록 큰 실수 하나에 훨씬 크게 반응하기 때문입니다.

> ⚠️ **함정** — RMSE 배율을 MSE 배율(4배)과 헷갈리기 쉽습니다. 루트를 씌우면 배율도 √4 = 2배로 줄어듭니다. 또 이상치가 커질수록 MAE와 RMSE의 격차가 벌어진다는 방향성을 반대로 기억하지 않도록 주의합니다.

**[REG-5] 정답 — 모든 샘플을 실제값의 평균으로만 예측한 것과 같다.**

R² = 1 − SSE/SST 에서 SST는 '전부 평균으로 예측했을 때의 오차 제곱합'입니다. 따라서 R² = 0 은 SSE = SST, 즉 모델이 평균으로 찍는 것과 똑같은 성능이라는 뜻입니다. 분류에서 '전부 미가입으로 찍어도 정확도 88.3%(Bank Marketing)'가 진짜 기준선이었던 것처럼, 회귀에서는 평균 예측(R²=0)이 기준선입니다.

> ⚠️ **함정** — R² = 0 을 '예측이 전부 틀렸다', '오차가 0이다' 로 해석하는 실수가 많습니다. 완전히 틀린 것이 아니라 '아무 정보도 추가하지 못했다'는 뜻입니다.

**[REG-6] 정답 — ②**

MAE는 모든 오차를 동등하게 평균 내지만 RMSE는 오차를 제곱하므로 큰 실수에 크게 반응합니다. A는 MAE가 낮으니 평소에는 더 정확하지만 RMSE가 높다는 것은 가끔 크게 헛짚는 예측이 섞여 있다는 뜻입니다. 실습1에서도 'MAE는 좋아졌는데 R²는 나빠진 모델'이 있었고, 지표 하나만 보면 판단이 뒤집힌다는 것을 확인했습니다.

> ⚠️ **함정** — 'MAE가 낮으면 무조건 좋은 모델'이라고 단정하는 것이 함정입니다. 또 RMSE ≥ MAE 는 수학적으로 항상 성립하는 성질일 뿐 과적합의 근거가 아닙니다.


## 3. 분류 알고리즘

**[CLA-1] 정답 — ④**

SVM은 두 집단을 가를 수 있는 무수히 많은 경계선 중에서 양쪽 데이터와의 간격(margin)이 가장 '넓은' 경계를 고릅니다. 간격이 넓을수록 새로운 데이터가 조금 다른 위치에 와도 안전하게 맞힐 수 있기 때문입니다. ①②③은 교재 설명 그대로 맞는 짝입니다.

> ⚠️ **함정** — '가장 좁은'과 '가장 넓은'을 대충 읽고 넘어가면 틀립니다. SVM은 경계를 '아슬아슬하게'가 아니라 '여유 있게' 긋는 모델이라고 기억하세요.

**[CLA-2] 정답 — O**

트리 계열은 '변수 A가 5보다 큰가?'처럼 <b>변수 하나하나의 기준값</b>으로 데이터를 쪼개기 때문에, 단위를 바꿔도 쪼개는 순서와 결과가 그대로입니다. 반면 KNN은 점 사이의 '거리', SVM은 경계까지의 '간격'을 재기 때문에 값의 범위가 큰 변수 하나가 계산을 지배해 버립니다. 그래서 KNN·SVM은 스케일링이 사실상 필수입니다.

> ⚠️ **함정** — 실습2에서 '스케일링이 성능을 만들었다'는 결론 때문에 모든 모델에 스케일링이 필수라고 외우기 쉽습니다. 그 결론은 거리 기반인 KNN에 해당하는 이야기입니다.

**[CLA-3] 정답 — ㉠ 마진(margin), ㉡ 서포트 벡터(support vector)**

SVM은 경계에서 가장 가까운 점들까지의 거리(마진)를 최대한 벌리는 선을 고릅니다. 이때 경계 위치를 결정하는 것은 전체 데이터가 아니라 경계 근처의 소수 점들뿐이며, 이 점들을 서포트 벡터라고 합니다. 멀리 떨어진 점들은 위치가 바뀌어도 경계에 영향을 주지 않습니다.

> ⚠️ **함정** — '모든 데이터가 경계를 결정한다'고 생각하기 쉽지만, SVM에서 경계를 떠받치는 것은 서포트 벡터뿐입니다.

**[CLA-4] 정답 — (1) 0.87 (2) 0.40 (3) 0.60 (4) 0.48 (5) 0.90**

Accuracy = (TN+TP)/전체 = (810+60)/1000 = 0.87. Precision = TP/(TP+FP) = 60/150 = 0.40 — '가입한다'고 말한 150명 중 진짜는 60명. Recall = TP/(TP+FN) = 60/100 = 0.60 — 진짜 가입자 100명 중 60명을 잡음. F1 = 2×(0.40×0.60)/(0.40+0.60) = 0.48/1.0 = 0.48. 전부 미가입으로 찍으면 미가입 900명을 다 맞히므로 900/1000 = 0.90 입니다.

> ⚠️ **함정** — 학습한 모델의 Accuracy 0.87이 아무것도 안 한 기준선 0.90보다 <b>낮다</b>는 점이 핵심입니다. 또 Precision의 분모는 '실제 가입자 100명'이 아니라 '가입이라고 예측한 150명'입니다. 분모를 헷갈리면 Precision과 Recall이 뒤바뀝니다.

**[CLA-5] 정답 — ②**

가입자가 11.7%뿐이므로 전부 '미가입'으로만 찍어도 88.3%를 맞힙니다. 즉 Accuracy 0.89는 '잘한 것'이 아니라 기준선과 거의 같은 수준입니다. 반면 AUC는 임계값과 무관하게 '가입할 사람을 더 위쪽으로 순위 매기는 능력'을 재기 때문에, 찍기(0.50)와 학습한 모델(0.77~0.79)이 확실히 구분됩니다.

> ⚠️ **함정** — ③처럼 'AUC 0.5면 Accuracy도 0.5'라고 생각하기 쉽지만 두 지표는 재는 대상이 다릅니다. 불균형 데이터에서는 Accuracy가 높으면서 AUC가 0.5일 수 있습니다.

**[CLA-6] 정답 — ①**

로지스틱 회귀는 각 변수의 계수를 그대로 읽을 수 있어 '이 변수가 1 늘면 승인 가능성(정확히는 로그 오즈)이 이만큼 오른다 / 내린다'는 식으로 방향과 크기를 설명할 수 있고, 의사결정나무는 판단 경로를 if-then 규칙으로 그대로 보여줄 수 있어 (ㄱ) 설명 요구를 충족합니다. (주: 로지스틱 회귀의 계수는 확률이 아니라 로그 오즈의 변화량이라, 확률이 얼마나 움직이는지는 현재 확률 위치에 따라 달라집니다.) 또 (ㄴ)처럼 데이터가 수천 건 수준일 때는 교재 선택표대로 단순한 모델이 유리합니다. ②는 데이터가 적을 때 부적합하고 설명도 어렵습니다. ③ k=1 KNN은 Train을 그대로 외워버려 과적합이 심하고 판단 근거도 제시하기 어렵습니다. ④는 RBF 커널로 변환한 공간과 PCA 주성분 모두 원래 변수의 혼합이 되어 해석이 오히려 더 어려워집니다.

> ⚠️ **함정** — '성능이 좋은 모델 = 항상 좋은 선택'이라고 보면 ②나 ④를 고르게 됩니다. 문제의 조건이 '설명 가능성'과 '적은 데이터'라는 점을 먼저 읽어야 합니다.

**[CLA-7] 정답 — 학습 데이터의 각 점에게 가장 가까운 이웃은 거리 0인 '자기 자신'이라서 언제나 자기 라벨을 그대로 맞히기 때문. 교훈: Train 성능은 모델 선택의 근거가 될 수 없고 반드시 Validation/Test로 판단해야 한다.**

KNN은 학습 단계에서 데이터를 통째로 기억할 뿐이므로, 학습 데이터를 다시 넣으면 자기 자신이 최근접 이웃(거리 0)으로 뽑힙니다. k=1이면 그 이웃 하나의 라벨을 그대로 답하므로 무조건 정답이 됩니다. 즉 Train 정확도 1.0은 모델이 좋아서가 아니라 구조상 자동으로 나오는 값입니다.

> ⚠️ **함정** — Train 정확도 1.0을 보고 '성능이 완벽하다'고 판단하는 것이 가장 흔한 실수입니다. 이는 전형적인 과적합 신호입니다.


## 4. 분류 성능지표 (혼동행렬)

**[MET-1] 정답 — ③ FN (False Negative)**

혼동행렬 이름은 '앞글자 = 예측이 맞았나(True/False), 뒷글자 = 모델이 뭐라고 예측했나(Positive/Negative)' 순서로 읽는다. 모델이 '정상(Negative)'이라고 했는데 그게 틀렸으니 False Negative, 즉 FN 이다. 교재 표현으로는 **'놓침'** 에 해당하며, 암 진단에서 가장 치명적인 오류라 Recall 을 중시하는 이유가 된다.

> ⚠️ **함정** — '실제가 암(Positive)이니까 P 가 들어간 TP/FP 겠지'라고 실제 라벨 기준으로 읽으면 틀린다. Positive/Negative 는 **모델의 예측** 기준이다.

**[MET-2] 정답 — X**

Accuracy 는 (TP+TN)/전체 이므로 다수 클래스만 맞혀도 높게 나온다. 실습4 Bank Marketing(가입률 11.7%)에서는 **전부 '미가입'으로 찍기만 해도 Accuracy 가 0.8830** 이었고, 그 모델의 양성 Recall 은 0, AUC 는 0.5 였다. 즉 Accuracy 0.88 은 소수 클래스를 하나도 못 잡은 모델도 받을 수 있는 점수다.

> ⚠️ **함정** — 높은 숫자를 곧바로 '좋은 모델'로 읽는 습관. 불균형 데이터에서는 먼저 **'전부 다수 클래스로 찍으면 몇 %인가'** 라는 기준선(baseline)을 계산해 비교해야 한다.

**[MET-3] 정답 — (가) Accuracy = 0.93 (93%) (나) Precision = 0.90 (90%) (다) Recall = 0.60 (60%)**

Accuracy = (TP+TN)/전체 = (90+840)/1000 = 930/1000 = **0.93**. Precision = TP/(TP+FP) = 90/(90+10) = 90/100 = **0.90** — '사기'라고 지목한 100건 중 90건이 진짜 사기였다는 뜻이다. Recall = TP/(TP+FN) = 90/(90+60) = 90/150 = **0.60** — 실제 사기 150건 중 90건만 잡아냈다는 뜻이다.

> ⚠️ **함정** — Precision 과 Recall 의 분모를 바꿔 쓰는 실수. **Precision 은 '예측한 것'(세로 = TP+FP)이 분모, Recall 은 '실제인 것'(가로 = TP+FN)이 분모**다. 분자는 둘 다 TP 로 같다.

**[MET-4] 정답 — F1 = 0.72, 산술평균 = 0.75 → F1 이 더 작다**

F1 은 Precision 과 Recall 의 **조화평균**이다. F1 = 2 × (P × R) / (P + R) = 2 × (0.90 × 0.60) / (0.90 + 0.60) = 2 × 0.54 / 1.5 = 1.08 / 1.5 = **0.72**. 산술평균은 (0.90 + 0.60)/2 = **0.75** 이므로 F1 이 더 작다. 조화평균은 두 값 중 **낮은 쪽에 더 끌려가기** 때문에, 한쪽만 잘하고 한쪽은 못하는 모델에게 높은 점수를 주지 않는다.

> ⚠️ **함정** — F1 을 (0.9+0.6)/2 = 0.75 처럼 그냥 평균으로 계산하는 실수. 또 하나, 분자의 **2를 빠뜨리면** 0.36 이 나온다. 극단적으로 Precision 1.0 · Recall 0.0 이면 산술평균은 0.5 지만 F1 은 0 이 된다는 점을 기억하면 조화평균의 취지가 이해된다.

**[MET-5] 정답 — (가) 0.883 (나) 0 (다) 0.5**

전부 '미가입(음성)'으로 찍었으므로 TP=0, FP=0, FN=1170, TN=8830 이다. Accuracy = (0+8830)/10000 = **0.883**. Recall = TP/(TP+FN) = 0/1170 = **0**. 모든 샘플에 같은 점수를 주어 순위를 전혀 매기지 못하므로 ROC 곡선은 대각선이 되어 AUC = **0.5** 다. 교재 표의 실제 수치(0.8830 / 0.5000)와 같다.

> ⚠️ **함정** — Accuracy 88.3% 를 보고 '나쁘지 않은 모델'로 착각하는 것. 이 모델은 가입자를 **단 한 명도** 못 찾는다. 참고로 Precision 은 분모 TP+FP = 0 이라 수학적으로 정의되지 않으며(scikit-learn 은 관례상 0으로 처리) 그래서 이 문항에서는 묻지 않았다.

**[MET-6] 정답 — (가) 모델 B — Recall 중시 (나) 모델 A — Precision 중시**

암 스크리닝은 환자를 **놓치는 것(FN)** 이 치명적이다. 놓치면 치료 시기를 놓치므로, 헛짚어서 재검사를 더 하더라도 Recall 이 높은 모델 B 를 쓴다. 반대로 스팸 필터는 정상 메일을 스팸함에 넣는 **헛짚음(FP)** 이 치명적이다. 중요한 메일을 못 보게 되므로 Precision 이 높은 모델 A 를 쓴다.

> ⚠️ **함정** — 'F1 이 높은 쪽을 고르면 되지 않나'라고 생각하기 쉽다. F1 은 둘의 균형을 볼 때 쓰는 지표이고, **어떤 오류가 더 비싼가**가 정해져 있는 상황에서는 그 오류에 해당하는 지표를 우선한다.

**[MET-7] 정답 — ③ Precision 감소, Recall 증가**

임계값을 낮추면 '사기'라고 판정하는 기준이 **느슨해져서** 양성 예측 건수가 늘어난다. 그러면 진짜 사기를 더 많이 잡으므로 FN 이 줄어 Recall 은 올라가지만, 동시에 헛짚음(FP)도 늘어 Precision 은 내려간다. 교재에서 말한 **Precision–Recall 맞바꿈(trade-off)** 관계다.

> ⚠️ **함정** — ④ 를 고르기 쉬운데, ROC-AUC 는 **임계값을 0부터 1까지 전부 훑어서** 계산하는 지표라 임계값 하나를 바꾼다고 값이 달라지지 않는다. 임계값을 움직여도 변하지 않는 것이 AUC, 움직이면 변하는 것이 Precision·Recall·Accuracy 다.

**[MET-8] 정답 — O**

ROC 곡선은 임계값을 0에서 1까지 움직이며 (FPR, TPR)을 찍은 곡선이고, AUC 는 그 아래 면적이다. 아무 정보 없이 찍으면 곡선이 대각선이 되어 면적이 정확히 0.5 가 된다. 그래서 **0.5 = 찍기, 1.0 = 완벽**이 기준이며, 실습4에서 '전부 미가입' 모델의 AUC 가 0.5000 으로 나온 것이 바로 이 경우다.

> ⚠️ **함정** — '0.5 면 절반은 맞히니까 그럭저럭 아닌가'라고 읽는 것. AUC 의 0.5 는 '50% 정확도'가 아니라 **성능의 바닥(하한선)** 을 뜻한다. 참고로 AUC 가 0.5 보다 확실히 낮다면 예측을 거꾸로 뒤집어야 한다는 신호다.


## 5. 비지도학습 — 군집화 · PCA

**[UNS-1] 정답 — ③**

DBSCAN 은 밀도 기준(eps 반경 안에 최소 몇 개)을 못 채운 점을 어느 군집에도 넣지 않고 '노이즈'로 남기는 것이 가장 큰 특징입니다. 모든 점을 반드시 어딘가에 배정하는 것은 K-Means 와 Hierarchical 쪽입니다. 실제로 실습3의 고객 데이터에서는 eps 를 0.8~2.5 로 바꿔봐도 '군집 1개' 아니면 '노이즈 52%' 가 나와, ④ 의 설명대로 실패했습니다.

> ⚠️ **함정** — '노이즈를 남긴다'는 DBSCAN 만의 성질인데, 이를 K-Means 의 성질과 뒤바꿔 외우기 쉽다. 또 ④ 를 '틀린 말'로 오해하기 쉬우나, 밀도 차이가 없으면 DBSCAN 이 실패한다는 것은 맞는 설명이다.

**[UNS-2] 정답 — A = 0.6, B = −0.6 / 점 B 는 잘못 배정된 점이다**

점 A: (5 − 2) / max(2, 5) = 3 / 5 = 0.6 입니다. 점 B: (2 − 5) / max(5, 2) = −3 / 5 = −0.6 입니다. 실루엣이 음수라는 것은 '자기가 속한 군집(평균거리 5)보다 옆 군집(평균거리 2)에 더 가깝다'는 뜻이므로, 점 B 는 옆 군집으로 옮기는 편이 나은 잘못 배정된 점입니다.

> ⚠️ **함정** — 분모를 항상 b 로 두면 점 B 에서 −3/2 = −1.5 라는 범위 밖 값이 나온다. 분모는 a 와 b 중 '큰 값'이며, 그래서 실루엣은 언제나 −1 ~ 1 사이에 들어온다.

**[UNS-3] 정답 — 3개, 90.0%**

누적으로 더해보면 1개 50%, 2개 75%(0.50+0.25), 3개 90%(+0.15) 가 됩니다. 3개에서 정확히 90% 에 도달하므로 최소 개수는 3개입니다. 변수 5개 중 2개 축을 버려도 정보의 10% 만 잃는다는 것은, 원래 변수들끼리 겹치는(중복된) 정보가 많았다는 뜻입니다.

> ⚠️ **함정** — '90% 이상'을 만족하는 개수는 3, 4, 5개지만 문제는 '최소'를 묻는다 — 4개(96%)를 고르지 않도록 주의. 또 PCA 는 설명분산이 큰 순서대로 주성분이 나오므로 따로 정렬할 필요가 없다.

**[UNS-4] 정답 — X**

PCA 는 변수를 '고르는(선택)' 것이 아니라 여러 변수를 섞어 새 축을 '만드는(변환)' 방법입니다. 그래서 주성분은 원래 변수들의 가중합이고, '이 축이 대체 무슨 뜻인가'를 설명하기 어려운 것이 PCA 의 대표적 한계입니다. 변수를 골라 남기는 것은 SelectKBest 같은 Feature Selection 쪽입니다.

> ⚠️ **함정** — '차원이 줄었으니 변수가 줄어든 것'이라고 생각하기 쉽다. 실습2에서 30개 변수 → 주성분 5개는 '30개 중 5개를 고른 것'이 아니라 '30개를 섞어 만든 새 축 5개'다(그 5개가 원 분산의 84.9% 를 설명).

**[UNS-5] 정답 — ① 이상치 3명을 각각 1명짜리 군집으로 떼어내는 바람에, 나머지 437명의 '가장 가까운 다른 군집까지의 거리 b'가 멀리 있는 그 이상치까지의 거리로 바뀌어 크게 부풀었기 때문(군집을 잘 나눈 것이 아니라 비교 대상만 멀리 치운 것) ② 지표 최대화는 목적이 아니다 — 점수 1위가 곧 쓸모 있는 군집은 아니다**

실루엣은 점마다 s = (b − a) / max(a, b) 를 구해 전체 평균을 냅니다. 여기서 주의할 점은, 1명짜리 군집의 점은 같은 군집 안에 비교할 상대가 없어 a 를 정의할 수 없고 sklearn 을 포함한 표준 구현은 이런 점의 s 를 0 으로 처리한다는 것입니다. 즉 떼어낸 이상치 3명 자신이 높은 점수를 받은 것이 아니라, 점수를 끌어올린 쪽은 남은 437명입니다. 이들에게 a(자기 군집 안 평균 거리)는 그대로인데, b(가장 가까운 다른 군집까지의 평균 거리)가 '옆 덩어리'가 아니라 '멀리 떨어진 이상치 1명'으로 바뀌면서 크게 커집니다. b 가 a 의 약 2배가 되면 s ≈ 0.5 이고, 여기에 0점짜리 3명이 섞여 평균 0.498 이 나온 것입니다. 같은 이유로 Dunn(군집 간 최소거리 ÷ 군집 내 최대거리)도 이 결과에 1위(0.336)를 줬습니다. 결국 군집화에서 점수를 올리는 가장 쉬운 방법은 '이상치 몇 개를 떼어내는 것'이며, 440명 중 437명을 한 덩어리로 둔 결과는 세분화(Segmentation)로서 아무 쓸모가 없습니다. 그래서 실무에서는 점수가 꼴찌(0.188)여도 [132, 129, 118, 61] 로 고르게 나눈 K-Means 를 채택했습니다.

> ⚠️ **함정** — '실루엣이 높으면 좋은 군집'이라고 답하는 것. 다만 이 비교가 유효한 이유는 같은 좌표 공간·같은 k 에서 쟀기 때문이며, 원척도 0.548 과 로그변환 0.188 처럼 전처리 공간이 다른 점수끼리는 애초에 비교 자체가 성립하지 않는다.

**[UNS-6] 정답 — ②**

(가) 초승달은 '중심점에서 가까운 쪽'이라는 K-Means 의 기준으로는 갈라지지 않아, 밀도로 이어붙이는 DBSCAN 만 정답을 냈습니다(그때 Silhouette 은 오히려 DBSCAN 이 꼴찌 0.376 이었습니다). (나) 는 밀도 골짜기가 없어 DBSCAN 이 eps 를 어떻게 잡아도 '군집 1개' 또는 '노이즈 52%' 로 실패했고, 고르게 나눈 K-Means k=4 가 [132, 129, 118, 61] 로 실무에 쓸 수 있는 세그먼트를 만들었습니다.

> ⚠️ **함정** — 'DBSCAN 이 K-Means 보다 우수한 알고리즘'이라고 외우는 것 — 우열이 아니라 데이터 형태가 방법을 정한다. ④ 의 single 연결은 이 데이터에서 [437, 1, 1, 1] 처럼 '한 덩어리 + 이상치'로 쪼개져 세분화가 되지 않는다.


## 6. 과적합 · 검증 · 규제

**[VAL-1] 정답 — ③**

Train은 매우 좋은데 Validation이 나쁘면 모델이 학습 데이터를 '외워버린' 과적합 상태다(교재 4-5절 진단표). 과적합의 대책은 모델의 용량을 키우는 것이 아니라 억제하는 것이므로 Dropout·Early Stopping·Ridge 같은 규제를 쓴다. 과소적합은 Train과 Val이 '둘 다' 나쁠 때의 진단이다.

> ⚠️ **함정** — ④처럼 Train 성능을 억지로 낮춰 Gap만 줄이는 것은 대책이 아니다. Gap은 진단 지표일 뿐이고, 실제로 좋아져야 하는 것은 Validation 성능이다.

**[VAL-2] 정답 — X**

Validation 셋은 이미 '고르는 데' 사용됐기 때문에, 그 점수는 실제보다 좋게 나오는 낙관적 편향이 있다. 수십 번 비교하다 보면 우연히 그 Validation 셋에만 잘 맞는 설정이 뽑히기 때문이다. 그래서 한 번도 쓰지 않은 Test 셋을 마지막에 딱 한 번만 열어 최종 성능으로 보고한다(교재 5절 체크리스트).

> ⚠️ **함정** — Validation과 Test를 '둘 다 학습에 안 쓴 데이터'라는 이유로 같은 것으로 착각하기 쉽다. 학습에 쓰였는지가 아니라 '선택에 쓰였는지'가 기준이다.

**[VAL-3] 정답 — (1) 2,000개 (2) 1,600개 (3) 6,400개 (4) 15번**

(1) 10,000 × 0.2 = 2,000개가 Test로 빠지고 남은 학습용은 8,000개다. (2) 8,000 ÷ 5 = 1,600개가 한 Fold의 검증셋이고, (3) 나머지 4개 Fold인 8,000 − 1,600 = 6,400개로 학습한다. (4) 후보 1개당 5번 학습하므로 3 × 5 = 15번이다.

> ⚠️ **함정** — Test 셋을 뺀 8,000개가 아니라 전체 10,000개를 5등분해 2,000개로 계산하는 실수가 잦다. 또 학습 횟수를 후보 수와 곱하지 않고 5번이라고 답하기 쉽다.

**[VAL-4] 정답 — (1) Lasso (L1) (2) Early Stopping (3) Dropout**

Lasso는 L1 규제로 필요 없는 변수의 계수를 0으로 눌러 자동 변수 선택이 된다(교재 1절). Early Stopping은 Validation 성능이 개선되지 않는 시점에서 학습을 멈춰 과적합으로 넘어가는 것을 막고, 그래서 반드시 Validation 셋이 필요하다. Dropout은 매 학습 스텝마다 일부 뉴런을 꺼서 모델이 여러 경로로 골고루 학습하게 만든다.

> ⚠️ **함정** — (1)에 Ridge(L2)를 쓰면 오답이다. Ridge는 계수를 0에 '가깝게' 줄이기만 하고 정확히 0으로 만들지는 않는다.

**[VAL-5] 정답 — (1) 0.883 (88.3%) (2) 0 (3) 0.5**

(1) 전원을 미가입으로 찍으면 미가입 883명만 맞으므로 883 ÷ 1,000 = 0.883이다. (2) Recall = TP/(TP+FN) 인데 가입자를 한 명도 맞히지 못했으므로 TP=0, 즉 0/117 = 0이다. (3) 모든 사람에게 똑같은 예측을 해서 순위를 전혀 구분하지 못하므로 AUC는 찍는 것과 같은 0.5다(교재 4-3절 표).

> ⚠️ **함정** — 정확도 88.3%만 보면 꽤 좋은 모델처럼 보이지만, 정작 잡아야 할 가입자는 0명이다. 불균형 데이터에서는 '전부 다수 클래스로 찍었을 때의 정확도'를 먼저 계산해 기준선으로 삼아야 한다.

**[VAL-6] 정답 — ③**

모델 선택의 기준은 '보지 않은 데이터에서의 성능', 즉 Validation 점수이고 C가 0.85로 가장 높다. B는 Gap이 가장 작지만 Train조차 0.75로 낮은 과소적합 상태이며, 실습1에서도 Gap이 가장 작은 모델이 가장 나빴다. Gap은 상태를 진단하는 지표일 뿐 최소화 대상이 아니다.

> ⚠️ **함정** — ④도 그럴듯해 보이지만 Test 셋을 여러 모델 비교에 쓰면 그 순간 Test가 Validation이 되어 최종 성능을 믿을 수 없게 된다. Test는 모델을 다 고른 뒤 마지막에 한 번만 연다.
